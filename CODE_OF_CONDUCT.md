# Code of conduct

MiniFlow follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, and assume good intent. Harassment, insults and
personal attacks are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainer through the contact details on
[github.com/omernaci](https://github.com/omernaci). Reports are handled confidentially.
